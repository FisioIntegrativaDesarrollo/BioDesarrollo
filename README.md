# BioDesarrollo

Simuladores interactivos para la enseñanza de la Biología del Desarrollo, que permiten explorar procesos celulares, diferenciación, morfogénesis y formación de órganos mediante experimentos virtuales. No requieren instalar software.

## Simulaciones

| Simulación | Archivo |
| --- | --- |
| Segmentación holoblástica radial en el erizo de mar | `simulaciones/segmentacion-erizo-de-mar.html` |
| Embriología comparada de vertebrados | `simulaciones/embriologia-comparada-vertebrados.html` |
| Morfógenos en la embriogénesis humana | `simulaciones/morfogenos-embriogenesis-humana.html` |

## Cómo usarlas

Abre `index.html` en cualquier navegador moderno y elige una simulación. Cada archivo es autocontenido (HTML, CSS y JavaScript incrustados) y también funciona por separado.

Si el repositorio tiene GitHub Pages activado, el sitio queda disponible en `https://fisiointegrativadesarrollo.github.io/BioDesarrollo/`.

## Cómo agregar una nueva simulación

1. Guarda el archivo HTML en `simulaciones/` con un nombre sin tildes ni espacios.
2. Copia una tarjeta en `index.html` y cambia título, descripción y enlace.
